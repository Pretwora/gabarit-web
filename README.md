# Сайт стрелкового клуба «Габарит»

Одностраничный сайт-визитка: бесплатное обучение стрельбе из традиционного и олимпийского лука, фотогалерея, скачивание APK приложения «Габарит».

Стиль — дизайн-система приложения [Габарит](E:\Projects\Gabarit): тёмная тема, Inter, акцент `#E8352B`, без теней.

## Структура

- `index.html`, `assets/` — сайт (чистый статик, без сборки)
- `downloads/` — APK приложения
- `tools/optimize-images.mjs` — генерация webp из исходников фотосъёмки (папки `Разные фото/` и `Цвет/`, в git не входят)

## Локальный запуск

```bash
npx serve -l 4173 .
```

## Обновление фотографий

Положить исходники в `Разные фото/` или `Цвет/`, поправить `SELECTION` в `tools/optimize-images.mjs`, затем:

```bash
cd tools && npm i && node optimize-images.mjs
```

## Деплой

GitHub Pages, ветка `main`, корень репозитория. Пуш в `main` → автопубликация.
